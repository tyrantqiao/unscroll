# v0.3 双时长规则

日期：2026-10-05。每个开启管控的应用都有今日总时长和本轮连续时长，两套规则可分别开启。现有旧版规则继续作为连续规则，每日规则默认关闭，避免升级后新增限制。

- **连续使用**：亮屏、解锁、目标应用在前台时累计。离开应用或锁屏结束当前连续轮次；首页同时展示最近一轮时长。原先“短暂切走仍合并为一轮”的定义在本版改为真正连续使用。
- **今日总时长**：本地服务已监测的当天累计，不因切换、休息或关闭规则清零。未开启管控或服务未运行期间不补算历史用量，页面有覆盖范围说明。
- **连续规则**：独立提醒阈值、中断阈值、休息时长；达到中断进入冷静期，期间重开仍拦截。休息结束恢复。
- **每日规则**：独立提醒阈值和累计上限；达到上限只限制该应用至设备本地次日。跨午夜总时长分日，连续时长不因午夜中断。
- **小提醒**：连续规则开启时，达到 10、30、60 分钟各提醒一次；每次显示 4 秒顶部提示，不获取焦点、不拦截触摸、不锁屏。新一轮可再次提醒。若连续上限为默认 20 分钟，将只遇到 10 分钟提醒；若要体验 30/60 分钟提醒，需要将连续上限设为更长。
- **同时触发**：每日中断优先于连续中断，中断优先于自定义提醒，自定义提醒优先于小提醒。相同时刻只展示一次，不叠加窗口。
- **锁屏**：开启后，每次连续冷静期或每日超限当天仅尝试一次系统锁屏。解锁后仍可使用其他应用。
- **配置**：连续和每日提醒均需小于对应上限。可单开或同时开启，应用启用时不能两套都关闭。上限最高 1440 分钟；休息 1–60 分钟。

测试：每日/连续独立计数、10/30/60 提醒去重、离开重置、每日恢复、冷静期、碰撞优先级、跨午夜分配、保存与旧版迁移。真机验证仍需覆盖目标 ColorOS 构建和后台存活。

真机快速验证：为一个应用分别设置连续 1 分钟提醒/2 分钟中断/1 分钟休息，每日 3 分钟提醒/4 分钟上限。分多轮使用，应分别看到连续冷静期与每日限制至次日。小提醒按真实 10/30/60 分钟测试，建议临时把连续提醒/上限设为 90/120 分钟。

限制：调整系统日期/时区会按新本地日期读取账本，尚不支持防篡改时间。服务中断后不能证明连续使用仍在进行，恢复时从新一轮开始；同次开机的已触发冷静期保留。

验证记录：v0.3 调试 APK 构建通过，16 项单元测试通过（10 项时长策略、6 项规则存储），Android lint 为 0 错误/4 警告，APK 签名校验通过。尚未进行 OPPO Find X8 Ultra 真机测试。
