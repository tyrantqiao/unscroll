# Unscroll Android

面向个人使用的 Android 时长提醒与休息中断应用。首版适配目标为 OPPO Find X8 Ultra；ColorOS 真机结果待确认。

## 已实现

- 当前用户空间的已安装应用列表（有桌面入口），展示名称、图标、搜索和已开启筛选；每个应用独立开关、独立规则，默认关闭。
- 无障碍服务识别当前主要应用；仅使用窗口包名，不遍历页面内容。
- 单轮计时、一次提醒、全屏休息覆盖层、冷静期内重开拦截。
- 可选一次系统锁屏；请求失败保留应用中断。
- 本地规则与同次开机内计时恢复；今日已监测时间。
- 权限自检、授权说明、系统设置入口。

首版采用 Java + Android 原生控件，减少构建依赖，先验证平台能力。设计中的 Compose、临时放行、完整历史统计与专门的 ColorOS 向导尚未实现。

## 构建

JDK 17、Android SDK 35、Gradle Wrapper 8.11.1。配置本地 `local.properties` 的 `sdk.dir`，执行 `gradlew.bat :app:assembleDebug :app:lintDebug`。
调试包输出：`app/build/outputs/apk/debug/app-debug.apk`。项目内 `.tooling` 是当前机器构建缓存，不提交；不要将其路径写入版本化配置。

## 真机验证

1. 安装调试 APK，打开设置并阅读授权说明，手动开启 Unscroll 无障碍服务。
2. 在“应用”页选择任意普通应用，配置：1 分钟提醒、2 分钟中断、1 分钟休息。
3. 连续使用到提醒，确认提示可见；继续到中断，确认休息页覆盖。
4. 回到桌面，再次打开目标应用，确认冷静期内拦截；使用其他应用应正常。
5. 测试离开 10 秒后返回计时保留，离开完整冷静期后计时重置。
6. 单独开启锁屏选项；确认只锁一次，解锁后能使用手机和打开 Unscroll 关闭规则。
7. 检查省电、清理任务、服务撤销、重启、分屏与小窗。记录系统构建号和结果。

系统设置与紧急呼叫保持可访问。覆盖层使用不获取焦点的窗口，系统导航仍由系统控制；真实手势行为需验证。统计只覆盖服务运行期间，不能代替完整系统用量。锁屏请求成功仅代表 API 接受，实际效果需观察。重启后不会恢复上一开机的单调计时状态；不承诺跨重启冷静期。

## 计时测试

`tests/SessionTest.java` 是纯 Java 策略测试，覆盖提醒去重、中断、冷静期、短切换保留、长离开重置和负时间防护。编译运行不需要 Android SDK。

v0.2 支持任意已配置应用，旧版本规则自动迁移。必要系统应用（电话、设置、桌面、Unscroll）只展示，不允许管控。无桌面入口的后台组件、工作资料及 ColorOS 应用分身不保证展示；以当前用户空间查询结果为准。卸载应用后刷新列表会移除展示，配置保留供同包名重装恢复。

产品文档：`docs/product-design-v0.1.md`；浏览器交互稿：`docs/prototype.html`。

## 快速开启与统计

- 首次进入快速开启页：开启 Unscroll 无障碍服务、选择应用并启用规则；返回应用自动检测系统开关和实际服务连接状态。已授权但未连接时明确提示等待连接。
- 优先进入本服务的无障碍详情页，无法打开时回退到无障碍列表。系统开关仍需用户确认。首页、应用页与设置页均可重新进入引导。
- 后台与电池设置为可选项；现有监测统计不需要额外授予使用情况访问权限。
- 底部“统计”展示当前已开启规则且已安装的可管控 App：今日 / 近 7 天总时长、每日明细、用量排行与占比、今日每日上限进度、本轮与最近一轮连续时长。
- 复用已有本地每日监测数据；关闭规则只隐藏该 App，不删除历史。无记录显示 0。日期按设备本地日历计算，近 7 天含今日。

验证：首次启动 / 稍后设置 / 重新进入引导；取消授权；开启后返回；开关已开但服务未连接；配置规则后返回完成；撤销服务后重新引导。统计需检查空列表、零用量、多个 App 排序、今日 / 7 天切换、每日上限前后、关闭再开启规则及跨日。系统详情页跳转与 ColorOS 后台设置仍需真机确认。


## v0.3 双时长

每应用独立配置连续使用规则与每日总时长规则。连续 10/30/60 分钟提供不阻塞操作的小提醒。每日达到上限限制至次日；连续达到上限进入冷静期。离开目标应用结束当前连续轮次，今日累计保持。首页显示两个时长和最近一轮时长。旧版连续配置保留，每日规则默认关闭。

行为、边界和真机测试参见 `docs/dual-duration-rules.md`。本地服务已监测用量不等于系统全部历史用量。执行 `gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug` 验证。
